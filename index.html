AI Studio Portable Recovery

A personal backup workflow using restic encryption and rclone to store recovery snapshots in its owner's Google Drive.

This is not a public backup service. This website has no sign-in, uploads, analytics, cookies or access to backups. It only explains the owner's private backup application.

Google authorization requests the drive.file permission, covering specific files used with the app. It does not request general access to all Drive files.

Backup contents are encrypted on the owner's computer before transfer. Recovery requires a separately protected encryption password and access to the owner's storage.
